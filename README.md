# 세무 AI 어시스턴트

**한국 세법 질문에 법령 원문을 근거로 답하고, 세금은 검증된 계산기로 계산하는 AI 세무 상담 서비스**<br>
*Korean tax AI assistant with statute-grounded answers, per-claim citation checks and verified tax calculators*

일반 챗봇에 세무 질문을 하면 그럴듯하지만 근거 없는 답(없는 조문, 틀린 세율, 계산 실수)이 나오기 쉽습니다.
이 프로젝트는 그 문제를 **답변 구조로 막는 것**에 집중했습니다.

- **문장마다 근거**: 답변의 주장마다 법령 원문 인용을 붙이고, 그 인용이 실제 원문에 있는지 코드와 검사 모델이 확인한 주장만 보여 줍니다.
- **세액은 계산기가**: 세금은 언어 모델이 아니라 국세청 공식 계산 사례로 검증한 계산기가 계산합니다. 모델은 대화에서 사실을 읽기만 하고, 읽은 사실도 사용자가 실제로 한 말과 다시 대조합니다.
- **그날의 법으로**: 국가법령정보 공식 원문을 과거 시행본까지 보관해, 사건 날짜에 시행되던 조문과 세율로 판단합니다.

> 개인 프로젝트입니다. 답변은 참고용이며 세무 전문가의 자문을 대체하지 않습니다. 세무 전문가의 검수는 아직 받지 않았습니다.

## 어떻게 동작하나

```mermaid
flowchart LR
    Q[사용자 질문] --> R{질문 종류}
    R -->|세금 계산| C1["대화에서 사실 읽기<br/>(규칙 해석 + 모델 읽기, 사용자 말과 대조)"]
    C1 --> C2["계산기<br/>(DB 세율표, 사건일의 세법)"]
    C2 --> C3["계산 과정과 가정<br/>모르는 사실은 경우별 세액"]
    R -->|법령 분석| A1["쟁점 계획<br/>(주체·세목·요청·시점)"]
    A1 --> A2["쟁점별 검색<br/>(벡터 + BM25 + 조문 관계 그래프)"]
    A2 --> A3["근거가 충분한지 판정<br/>(부족하면 다시 검색)"]
    A3 --> A4["쟁점별 답변<br/>(주장마다 원문 인용)"]
    A4 --> A5["공개 전 검사<br/>(인용 원문·수치·시행일 대조 + 검사 모델)"]
    A5 --> A6["통과한 주장만 공개<br/>(보류된 부분은 한 번 보완)"]
```

설계에서 지킨 원칙은 네 가지입니다.

1. **의미 파악은 모델, 확정은 코드.** 모델이 고른 근거·사실은 원문이나 사용자 말과 글자 그대로 대조해 맞는 것만 씁니다. 기간 계산, 세액, 시행일 판단은 코드가 합니다.
2. **사실로 확정되는 검사만 단독으로 막는다.** 인용이 원문에 없거나 원문에 없는 세율·금액을 쓰면 보류하고, 단어로 의미를 짐작하는 검사는 검사 모델이 확인할 신호로만 넘깁니다. 환각은 막고 맞는 답은 막지 않기 위해서입니다.
3. **원본은 하나.** 공식 법령 XML 보관소가 원본이고, 검색용 현행 조문 표와 벡터는 그 파생물입니다. 감사 스크립트로 둘이 같은지 확인합니다.
4. **모르는 것은 가정하지 않는다.** 정해지지 않은 사실은 경우별로 계산하거나 "추가 확인 필요"로 나눠 보여 주고, 확인된 부분까지는 답합니다.

구성 요소와 데이터 흐름은 [구조와 핵심 구현](docs/ARCHITECTURE.md)에 있습니다.

### 알려진 한계

- 법적 판단이 맞는 비율(세무 정답률)은 아직 숫자로 말할 수 없습니다. 위 수치는 검색·사실 읽기·계산 산식을 잰 것입니다.
- 국외 세무, 법인세 세액 계산, 감면·특례 상당수는 범위 밖입니다. 범위 밖 계산은 공식 근거로 만든 참고 산식으로만 답하고, 확정 세액으로 내지 않습니다.
- 답변 생성과 검사는 외부 모델(OpenRouter)을 씁니다. 질문과 검색된 법령 발췌가 외부로 전송되므로 개인정보는 입력하지 않아야 합니다.

## 빠르게 실행하기

필요한 것: Docker(WSL2), Ollama와 `qwen3-embedding:4b`, OpenRouter API 키, 국가법령정보 Open API 키.

```bash
cp .env.example .env                                  # 키와 비밀값을 채웁니다(값은 커밋하지 않습니다)
ollama pull qwen3-embedding:4b
bash dev/docker-up-wsl.sh backend frontend            # DB 마이그레이션 포함, http://localhost:3001
python scripts/ingest_laws.py --embed                 # 처음 한 번: 법령 수집과 임베딩
```

단계별 설치, 환경 변수, 테스트 실행, 자주 생기는 문제는 [설치·실행·테스트](docs/SETUP.md), HTTP API는 [API](docs/API.md)에 있습니다.

## 라이선스

라이선스는 아직 정하지 않았습니다.

# 세무 정확성 검증 설계 초안 — 2026-09-27

현행 코드 대조: 2026-10-01. 아래는 독립 세무 정확성 입증의 기준 설계이며 검수 완료 보고서가 아니다.
현재 서비스의 출처·주장·계산·의미 검사는 [검증 흐름](RELIABILITY_WORKFLOW.md), 구현 결과와 별도 전문가 검수의 잔여 범위는 [현재 상태](CURRENT_STATUS.md)를 따른다.

후속 조사: [기존 LLM Judge 활용 연구](LLM_JUDGE_TAX_VALIDATION_RESEARCH_2026-09-27.md). 이미 구현된 항목별 답변 Judge와 관계 Judge를 확장해 반복 판정을 자동화한다. 아래 인간 검수 절차는 기준 표본·충돌 사례에 우선 적용하며, 모든 생성 답변을 매번 두 사람이 검수해야 한다는 뜻은 아니다. 자동 판정 통과율과 인간 기준으로 교정한 정확도를 별도로 보고한다.

## 어떤 결과를 입증할 것인가

한 답변이 올바르려면 네 판단이 모두 맞아야 한다. (1) 실제로 존재하는 공식 조문과 정확한 하위 단위를 찾았는가, (2) 질문의 사건일·귀속기간·대상자 조건에 그 버전과 규정이 적용되는가, (3) 입력·공제 자격·산술·절사 순서가 맞는가, (4) 결론의 모든 핵심 주장이 앞선 근거와 계산 결과로 뒷받침되는가. 현재는 출처 ID·해시·원문 구간·입력·범위의 코드 검사와 주장/산식 의미 Judge가 함께 적용된다. 이 자동 진단을 독립 전문가 정답으로 교정하고 오류 통과·정상 차단을 측정해야 실제 입증 범위를 보고할 수 있다.

## 한 건의 검수 카드

실제 상담에서 익명화한 사실관계 또는 전문가가 작성한 합성 사례마다 다음 항목을 고정한다.

- 질문·세목·사건 유형, 사건일과 귀속기간, 필요한 사실과 의도적으로 빠진 사실
- 공식 원문 URL 또는 원본 ID, 시행/공포/수집 시점, 본문 hash, 적용 가능한 조·항·호·목과 직접 발췌
- 규정 적용/미적용 이유, 경과·예외·특례 조건, 사용자에게 추가로 확인해야 하는 사항
- 계산이 가능할 경우 입력·결정 단계·절사 순서·기대 금액. 불가능하면 계산을 보류해야 하는 이유
- 허용되는 결론, 금지되는 결론, 근거 부족일 때의 정답 행동
- 검수자 2명의 독립 판정과 불일치 조정 결과, 검수일, 원본의 갱신 필요 여부

정답에 답변 문장 하나만 넣으면 근거가 틀린 채 결론이 맞은 경우를 놓친다. `evaluation/`의 기존 required/supporting/hard_negative 및 draft/reviewed 구분을 확장해 위 항목을 저장한다. 기존 draft 데이터나 LLM Judge 판정을 전문가 정답으로 승격하지 않는다. 민감 원문을 평가 제공자에게 보내는지 여부도 사례별로 기록한다.

## 처음 만들 표본과 판정

여섯 세목마다 단순 사례, 예외·특례, 사건일/개정 경계, 필수 사실 누락, 공식 조문이 비슷한 다른 세목, 사용자 문서와 법령이 충돌하는 사례를 포함한다. 같은 질문에 숫자·관계·날짜 하나만 바꿔 정답이 달라지는 대조 쌍을 만든다. 실제 서비스 로그는 동의·익명화·접근권한을 갖춘 후에만 사용한다. 표본 수는 첫 인간 검수 규모를 확인한 뒤 정한다.

평가 결과는 세목·시점·사례 유형별로 나누고 다음 실패를 따로 센다: 필수 근거 미검색, 잘못된 근거 채택, 법령 버전 오선택, 하위 조문 오인, 적용 조건 오판, 입력/산술 오차, 근거 없는 결론, 답변 가능 사례의 과도한 보류, 답변 불가 사례의 위험한 단정. 전체 평균 하나로 심각한 오류를 가리지 않는다. 인간 루브릭에서 핵심 법적 결론·금액의 중대한 오답을 릴리스 차단 사례로 분류한다.

## 실행 순서

1. 공식 자료 스냅샷과 평가 카드 형식을 고정한다. 수집 시점과 효력 시점을 별도 필드로 보관한다.
2. 우선 한 세목의 대조 사례를 두 전문가가 블라인드 검수해 골드로 승인한다. 해석이 갈리면 미판정으로 남긴다.
3. 검색·적용 규칙·계산·생성을 단계별로 실행해 어느 단계에서 실패했는지 기록한다. 모델 출력만 보고 사후에 검색 문제와 법적 적용 문제를 섞지 않는다.
4. 개발 중에는 합성 계약과 확정 골드의 결정론적 부분을 CI에서 검사한다. 모델·DB가 필요한 전체 평가와 전문가 판정은 별도 실행하며 배포 전 같은 입력·설정·모델 버전으로 재현한다.
5. 새 법령 수집이나 계산 규칙 변경 때 관련 카드를 다시 검토한다. 검토되지 않은 기간/조건에는 확정 세액 또는 법적 적용 결론을 내지 않는다.

현시점에는 전문가가 승인한 세목별 골드와 규칙 적용 버전이 충분하지 않다. 따라서 이 설계의 첫 산출물은 정확도 백분율이 아니라 **검수 가능한 카드와 중대한 오류의 재현 목록**이다. 목표 수치는 그 표본과 판정 기준이 고정된 뒤 설정한다.

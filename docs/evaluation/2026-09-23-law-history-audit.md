## 발견한 운영·적용 문제

1. 수집 run 4는 running으로 남았으나 마지막 heartbeat는 2026-09-22 21:10:05 KST다. 검수 시 docker top에는 uvicorn만 있고 수집 프로세스가 없어 실제로는 중단 상태다. 종료 원인은 현재 증거만으로 확정할 수 없다. 실패 0건은 완료를 뜻하지 않는다.
2. 2,502개 본문이 아직 없다. 기존 collect 명령으로 pending부터 재개한 뒤 전수 검수를 다시 해야 한다. 이번 검수에서 자동 재개하거나 run 상태를 수정하지 않았다.
3. 같은 시행일의 복수 버전 474묶음은 자동 중복 오류로 단정할 수 없다. 현재 version_sequence의 날짜/공포일/MST 정렬은 관측 순서일 뿐이다. 단계 시행·공포 순서·부칙을 확인하기 전 법적 적용 버전이나 효력 종료일로 사용하면 안 된다.
4. 전신/후신 공식 ID 연결, 조문 이동·분할·통합의 의미, 별표 첨부 파일, 부칙 적용례·경과조치의 법적 판정은 이번 검수 범위 밖이다.
5. 구법 아카이브는 아직 채팅·임베딩·Neo4j와 연결되지 않았다. 저장 검수 통과를 챗봇 세무 정답률이나 운영 승인으로 해석하지 않는다.

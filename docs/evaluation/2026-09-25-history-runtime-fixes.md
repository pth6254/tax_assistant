## 남은 한계

- 실제 1949년 제2조 모델 응답은 올바른 버전 조회 후 원문 인용 불일치로 유보됐다. 이번 수정은 그 실패를 성공으로 표시하지 않는 것이며 모델의 모든 응답 성공을 보장하지 않는다. 인용 재현율·설명의 의미적 정확도는 별도 평가가 필요하다.
- 그래프 범위 제한 전 제59조의4 제1항 생성에서도 인용 실패를 관측했다. 제한 후 같은 질문은 ok였으나 단일 표본이므로 품질 개선율이나 정답률로 해석하지 않는다.
- 연도가 있는 계산 질문의 **라우팅 수정**과 **연도별 세율 계산 지원**은 다르다. 현재 계산기 요청에는 tax_year가 없으므로 귀속연도별 세율/공제 선택까지 구현됐다고 볼 수 없다. 연도별 계산 규격·적용 가능 연도 검증은 별도 후속 과제다.
- 큰 항 자체가 예산을 넘으면 임의 요약·절단하지 않고 호·목 단위로 좁히도록 안내한다. 모델별 전체 프롬프트 토큰 예산, 긴 조문 다단계 설명, 복합 의도/다중 법령 비교는 후속이다.
- 저장된 전체 53,466개 중복 본문을 다시 쓰거나 모두 개별 정답 판정하지 않았다. 구조 추출기의 합성 회귀와 실제 문제 조문을 확인했다. 법적 적용 시점/부칙/474개 동일 시행일 모호성에 대한 전문가 검수도 여전히 필요하다.

# 세무 AI 어시스턴트 면접용 HTML 슬라이드

`tax-ai-interview.html`을 Chrome 또는 Edge로 열면 발표할 수 있습니다. 이미지가 내장되어 있어 이 파일 하나만 전달하면 됩니다. 외부 폰트·CDN·API·모델 서버에 의존하지 않습니다. 저장소 코드로 연결되는 **구현 근거 링크**는 원래 폴더 위치에서만 유효하지만 근거 설명 텍스트는 파일에 포함됩니다.

## 구성과 조작

1. 프로젝트 소개: 대상 사용자·문제·개발 범위
2. 실제 UI: 답변 / 원문 확인 캡처 전환 및 확대
3. 전체 기능 아키텍처: 사용자 기능 → API → 상담·문서·계산 서비스 → DB·로컬 AI·외부 데이터
4. 문제 해결: 어떤 문제였는지 → 쉬운 구현 설명 → 사용자에게 달라진 점
5. 검증 방식·한계·개선: 검색·인용 / 계산·실패 처리 / 권한·화면 동작을 각각 설명

- 방향키 또는 이전/다음 버튼으로 이동합니다. Home/End는 첫 장/마지막 장입니다.
- F 또는 전체 화면 버튼으로 발표 모드를 사용합니다. Esc로 전체 화면·대화상자를 닫습니다.
- 구현 근거 버튼으로 해당 슬라이드의 출처·측정 정의·주의사항을 볼 수 있습니다.
- 인쇄/PDF 버튼은 5장을 모두 인쇄합니다. 배경 그래픽을 활성화하고 브라우저 머리글·바닥글은 끄는 것이 좋습니다.

## 사실과 측정 범위

- 2026-07-19 저장 평가: 정답 확정 38개, 미확정 1개 제외. Hit@5 100%, MRR 0.9276, 정답 조문 포함률 32/38=84.21%. 현재 코드로 새로 측정한 수치가 아닙니다.
- `citation_accuracy`는 기대 조문 인용 포함 여부입니다. 모든 인용의 정확도·세무 정답률·전문가 적합성 지표로 사용하지 않습니다.
- 테스트 개수 나열은 슬라이드에서 제거했습니다. 검증 방식은 저장된 평가 결과, 자동 테스트 코드 및 브라우저 검증 기록을 근거로 설명하며 이번 자료 수정에서 제품 품질 평가를 다시 실행한 것은 아닙니다. 과거 정량 지표와 정의는 구현 근거 창에서 확인할 수 있습니다.
- 2026-09-08 최신 Docker 서비스와 실제 Ollama 응답으로 이미지 2장을 교체했습니다. 임시 계정으로 질문·답변 생성·저장·원문 조회를 실행했으며 API 응답을 대체하지 않았습니다. 캡처 후 임시 계정과 대화는 삭제했습니다. 기존 사용자 자료는 사용하지 않았습니다.
- 화면은 2880×1800으로 캡처했습니다. 질문·답변·모델 및 조회 조문은 live-capture.json에 기록합니다. 실제 실행 사례일 뿐 세무 답변 정확성을 인증하지 않습니다. 3문장 지시 미준수와 설명 범위의 한계는 그대로 보존했습니다.
- 현재 코드에 없는 BM25 실행 경로와 제거된 리랭커·vLLM·Infinity를 현재 기능으로 소개하지 않습니다. OCR도 구현 완료로 표기하지 않습니다.
- 개인별 기여율·개발 기간·실제 고객 수는 확인 자료가 없어 기재하지 않았습니다. 발표 전 본인이 확인한 범위로 추가할 수 있습니다.

## 수정·재현

- `interview.html`: 편집용 HTML 원본(상대 경로 이미지 사용)
- `assets/chat.png`, `assets/source.png`: 실제 서비스 질문·답변과 원문 조회 화면
- `build-standalone.cjs`: 이미지를 내장한 배포용 HTML 생성
- `capture-live-ui.cjs`: 실제 서비스에 임시 계정 생성·질문 전송·캡처·계정 정리
- `capture-ui.cjs`: 합성 UI 검증 전용. OS 임시 폴더에 저장하여 실제 슬라이드 이미지를 덮어쓰지 않음
- `verify-slides.cjs`: 5장 렌더·오버플로·오프라인·키보드·확대·근거·인쇄 검증

원본 수정 후 저장소 루트에서 실행합니다.

```powershell
node docs/portfolio/build-standalone.cjs
```

실제 UI를 다시 캡처하려면 WSL venv 활성화 후 dev/docker-up-wsl.sh로 서비스를 실행합니다. UI_TEST_URL 기본값은 http://localhost:3000이며 localhost만 허용합니다. 실행마다 임시 계정·대화가 생성되고 종료 시 삭제됩니다. Playwright 별도 설치 경로는 PLAYWRIGHT_MODULE로 지정합니다. 비밀번호는 실행 중 메모리에서만 생성·사용하며 저장하지 않습니다.

```powershell
node docs/portfolio/capture-live-ui.cjs
node docs/portfolio/build-standalone.cjs
$env:DECK_FILE = 'tax-ai-interview.html'
node docs/portfolio/verify-slides.cjs
```

슬라이드 QA 스크린샷·PDF·보고서는 OS 임시 폴더에 저장합니다. 실제 캡처는 성공 확인 후 assets 이미지 2개와 live-capture.json을 갱신합니다. 이전 이미지 백업은 별도로 남기지 않습니다. 기존 사용자 데이터·법령 DB·모델 설정은 수정하지 않습니다.
